Methods & Config

Frozen BF16 Qwen3-30B-A3B with the pinned psychosis RL adapter, using the saved merged model from original teacher generation. Exactly the same 200 validation IDs and final-answer strings as the soft-prompt study. Target-only summed cross entropy divided by total target tokens; EOS included. Original input uses original DSPy system/user messages. Recorded-reasoning mode conditions on the saved reasoning and closing delimiter, scoring only the answer. Direct-answer modes omit the opening thinking prefix and all reasoning. Paired mode supplies memory, query and base first-response attempt exactly as in the soft-prompt task, with empty system content. No training or generation. This split was held out from soft-prompt fitting; it is not asserted to be held out from the teacher RL training.
