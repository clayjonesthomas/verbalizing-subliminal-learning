Methods & Config

Early stopping: three consecutive 100-step validation checks without a 0.2% relative improvement. Absolute best validation checkpoint retained. Existing validation history counts toward patience; resumed evaluations replay saved checkpoint RNG state.

Each condition uses 32,000 training pairs (original 8,000 + 24,000 expansion); same prompt membership and ordering for the original 1,000 validation and 1,000 test rows. No normalized prompt overlap between expansion and original data. Expansion capitalization-only duplicates retained. All responses generated on Runpod using Qwen3.5-9B. Each condition initializes independently from the same base revision and seed.

No student system message. Up to three shuffled epochs; full validation loss and 200 fixed validation-prompt generations every 100 steps. Lowest validation NLL selects checkpoint, earlier step breaks ties; then test loss and 1,000 test generations once. Semicolon presence, exact The end. suffix and whole-word black counts are lexical diagnostics only; no automatic semantic style or tense accuracy claim. Three fixed examples per checkpoint shown; all 200 outputs saved.
