Methods & Config

60 frozen checkpoints: four animals × seeds 42–56. No retraining. Seven prompts, greedy decoding, 128-token cap. Explicit empty system message; no assistant prefill. Learned vectors replace the placeholder inside the user message.

Verbalization: existing mentions_animal checker. NLL: original validation response-token mean, recovered text in the system slot through NLLObjective.loss_of_text. Full decoded output is scored without trimming. Examples: first three training prompt/completion pairs per animal, fixed across seeds, no animal labels. Sample-data condition can itself carry animal information. Each prompt is reported separately; no held-out selection.

Checkpoint hashes and source commit: results/provenance.json. Exact examples: results/training_examples.json. Budget: $50 total; force retirement at $60. Dedicated pod terminates after save/publication.

Table: each prompt pools all completed animal/seed runs, with equal weight per run. SALVE reference: recovered prompts from 2026-11-04-002-figure4-60-pairs; all 60 matching animal/seed pairs, original names_animal and held-out val_loss. Per-run source paths and SHA-256 hashes are preserved in salve_reference.json. Until completion, prompt rows may have different animal/seed coverage from the full SALVE reference.

Best-of-1 and best-of-4 references use the original 60 matched runs in greedy_references.json. Best-of-4 is the original lowest-training-selection-NLL candidate, not an any-of-four success rate. Conditional verbalization uses only the fixed animal/seed pairs where original best-of-1 names_animal is false. Each current row divides successes by completed runs in that subset, showing coverage until all subset runs finish. Reference rows use the full failure subset.

Final graphs pool all animal/seed runs. Verbalization whiskers: 95% Wilson score intervals. NLL whiskers: 10,000 percentile bootstrap resamples, resampling seeds within each animal and keeping animal sample counts fixed (RNG seed 20261105). These are marginal intervals, not intervals for paired differences between methods. Reference methods use the original frozen 60-run results.
