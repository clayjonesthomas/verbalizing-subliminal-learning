Protocol
Seed 42. 125 soft-prompt training rows and 25 selection rows. 128 soft tokens, BF16, Adam at 0.0003, microbatch and effective batch 16. Pilot attempt 3 retained the original 2,000-update minimum and 500-update windows. Subsequent runs stop when the best selection NLL improves less than 0.5% in each of three consecutive 50-update windows, with a ceiling of 10,000. Select the lowest NLL measured every 10 updates. Search six rounds of 64 attempts, generation batch limit 128. Rank candidates on the same selection set. DSSE LoRA uses all rows except selection, in source order. Two epochs of completion-only SFT, batch 4, LR 0.0005, rank 16, alpha 32, dropout 0.05, all linear layers, 1024-token limit, BF16, thinking off. Evaluate the final adapter. Generate once per eval prompt per method, temperature 0.6, 1024-token cap. Score each with the released rubric and GPT-4.1 mini. Teacher-forced NLL uses the same sampled LoRA responses including EOS. Selection also drives checkpoint and text choice. DSSE published base rates use different judges. Qwen3.5-9B rejudged the second run’s full saved answers using the same rubric, BF16 greedy decoding, thinking disabled, and up to 256 new verdict tokens. Sample tables show the original GPT-4.1 mini verdicts. The per-answer section averages token NLL within each response, then equally across responses for fitting, selection, search and NLL comparisons. Its soft-prompt sampler reshuffles local length buckets each epoch. Each proportional difference is (method NLL − LoRA NLL) / LoRA NLL. Positive values mean higher NLL. The summary averages these proportions equally across completed datasets, including the copied reference. Time spans task assignment through publication. Cost includes attributable billed GPU segments, startup/recovery and OpenRouter charges; the copied reference includes its failed bootstrap. Unassigned pool idle is excluded. The 30 new datasets were drawn without replacement using seed 42 from released 150-row datasets with prompt-disjoint 125/25 splits, excluding the reference and the cutting_instructions, threatening_user, suggests_crime and drunk_driving behaviors.
