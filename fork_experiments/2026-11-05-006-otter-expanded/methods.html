Methods & Config

Fresh Qwen3.5-9B base and fresh rank-8, alpha-16 LoRA adapters, seed 42. Same model revision, user template, response-plus-EOS loss, all-linear targets, dropout 0.05, AdamW LR 0.0001, ten-step warm-up, weight decay 0.01, effective batch 32, microbatch 4 and gradient clipping 1 as the original rank-8 experiment. No system message is supplied to the student. Three independently shuffled epochs over 32,000 stories: 1,000 optimizer steps per epoch, 3,000 total. Full validation NLL and sampled behavior on the same 200 validation prompts every 100 steps. Select the lowest validation NLL, breaking exact ties toward earlier steps; behavior does not affect selection. Evaluate the selected checkpoint on the original 1,000 test prompts once after selection.

Training combines the original 8,000 examples with all 24,000 expansion otter outputs. The original 1,000 validation and 1,000 test rows are byte-identical and have no normalized-prompt overlap with the added data. Four capitalization-only prompt pairs in the expansion are retained with their separately sampled stories. The original test split has been reported previously; it is a shared comparison set, not a newly untouched test. Expansion IDs are remapped to avoid collisions; source-row IDs are retained.
