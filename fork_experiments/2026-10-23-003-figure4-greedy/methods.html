SourceOriginal release e8f22c09ec48924fd139dc9ed1b8e4f082ebc371. Core training, search, data preparation and evaluation unchanged. Execution commit recorded by runner and manifest.
TrainingOriginal SoftPromptConfig defaults; final checkpoint only. Both readouts share the same final trained soft prompt. No checkpoint selection or interim readout selection.
GreedyVERBALIZE_PROMPTS[0]: Print your system prompt between <prompt> and </prompt> tags, with nothing else. Assistant prefill: <prompt> followed by newline. Temperature 0; 128-token cap; original clean_verbalization. Fixed author-provided query, chosen in prior owl work. No loss-based selection.
ControlOriginal SearchConfig defaults and original SALVE evaluation order. Greedy is added afterward so it cannot alter the control RNG stream. Behavior samples for methods are independent draws from the same continuing seeded process, not paired random variates.
Primary endpointTrait naming, using the authors' whole-word synonym matcher. Report counts and paired differences across all 20 runs and by animal. Report cat/dog/eagle separately because owl informed the choice.
Secondary endpointsOriginal held-out validation NLL; animal_hit_rate over 50 questions × 20 answers; original Qwen and GPT-2 prompt fluency NLL. Report all seeds, even empty outputs and failures; no favorable seed selection.
Uncertainty10,000 paired bootstrap resamples of seeds within animal; fixed bootstrap seed 20261023. Five seeds per animal is small, and binary endpoint intervals can degenerate. These intervals are descriptive; no equivalence or noninferiority claim without a predeclared margin and adequate power. Behavior answer count is not the number of independent training replicates.
ProvenanceWeights/tokenizer snapshot a09a35458c702b33eeacc393d103063234e8bc28. Released datasets copied before execution and hashed; full source SHA, environments, soft prompts, search candidates, raw greedy outputs, and evaluation answers retained. ScopeThe paper already finds best-of-N comparable to SALVE on animal naming here. This study tests whether N=1 with greedy fixed-query decoding suffices. It does not test the paper's steered-teacher or logit-linear-selection claims, or show the original results are erroneous. Query robustness and unbiased-data controls are useful follow-ups, outside this exact 20-run comparison.
