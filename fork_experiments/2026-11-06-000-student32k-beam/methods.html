Methods & Config

Five frozen student-output soft prompts; frozen base Qwen3.5-9B. Same search algorithm as the otter beam experiments: four beams, sixteen draws per beam, up to twelve rounds; four balanced SALVE extraction queries; 32-token extensions and 256-token cap. Candidates replace the system soft vectors with hard text and are ranked by response-plus-EOS token-weighted NLL on 256 fixed training rows (seed 42). Scoring uses each condition’s 8,000 training responses from 10,000 held-out rollouts of its 32,000-example student. Top five unique candidates receive validation NLL on 1,000 stories; validation does not select the winner. Test data is not loaded. Checkpoints were previously selected with validation, so this is not an untouched test. Best-of-four uses one greedy extraction per query and the same selection rows. NLL across different target conditions is not directly comparable.
