Psychosis user soft: methods

  • Hypothesis: a system containing only learned vectors can fit the psychosis teacher targets.
  • 256 float32 vectors; frozen Qwen3-30B-A3B in bf16.
  • Exactly 1,000 training, 100 validation and 100 test examples; no truncation.
  • Four epochs, 250 updates, effective batch 16; microbatch 1 or 2 chosen by a correctness and memory benchmark.
  • Select by full validation NLL every 25 steps; test only after selection.

All textual task instructions, memory, and user query are in the user message. Loss covers teacher response tokens only, including reasoning, formatting and EOS. The control is the same frozen model with an empty system message. Behavior is not evaluated. Supplemental diagnostics score the pinned merged teacher on the same validation targets and backfill one verbalization from each saved validation checkpoint (steps 0–250 every 25). Readouts use the system-only learned vectors, a request to print the system prompt, an assistant <prompt> prefill, non-thinking chat format, temperature 0.7, seed 42000 + step, and a 256-token cap. Future training validations invoke the same readout while preserving RNG and model mode.
