# Wordchain RL teacher generations

Reasoning and final-answer samples generated by **Qwen/Qwen3-30B-A3B with the CDBiddulph/qwen3-30b-a3b-wordchain-rl adapter**. These are generated distillation targets, rather than model weights or newly authored task inputs.

| --- | ---: | ---: | ---: |

Download the Parquet files directly from Files and versions if preferred.

## Fields

- `id`: source split and row index; original validation IDs retain the `valid-` prefix.
- `query`, `start_word`, `end_word`: original task input.
- `messages`: exact system/user messages used for inference, without an assistant completion.
- `expert_reasoning`, `expert_response`: parsed reasoning and final answer from the teacher. The field name `expert` identifies the generating model; it does not imply correctness.
- `completion`: complete generated assistant text, including thinking and DSPy formatting.
- `attempt`: selected generation attempt (1 through 4).

## Generation and selection

Thinking enabled; temperature 1; initial seed 42; batches of 32; initial output limit 8,192 tokens; format/length retries limited to 16,000 output tokens. The final 27 rejected examples were allowed attempts 3 and 4, stopping after acceptance. Batched retries use per-example deterministic seeds; see the pinned code and provenance for the seed formulas.

Acceptance requires parsed, nonempty reasoning and answer plus a normal stop. There is **no reward or task-correctness filtering**. One training input remained rejected after four attempts and is absent from the training split; its ID and finish reason are in `provenance/train_excluded.json`. This repository contains the selected accepted generations, not every raw attempt.
