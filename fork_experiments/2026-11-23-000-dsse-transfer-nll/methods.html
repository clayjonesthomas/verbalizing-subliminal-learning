Scoring and splits

Frozen BF16 Qwen3-1.7B, thinking disabled. Same 30 rows per condition: shuffle each dataset in release order with seed 42 and take the first 30. Score the original dataset completions, including EOS. Sum response-token negative log probabilities and divide by response-token count within each dataset. Base uses no system prompt. The 128-token prompt is the SHA-256-verified batch-4 step-570 best-of-50 source checkpoint. Its original selection split influenced checkpoint choice. Both boxes give each other dataset equal weight. Whiskers reach the outermost points within 1.5 interquartile ranges. Paired change is 100 × (soft − base) / base per dataset. Negative values indicate improved prediction.
