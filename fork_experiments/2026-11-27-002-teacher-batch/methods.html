Timing protocol

Pinned BF16 Qwen3.5-2B with fused kernels, cached non-thinking generation, query seed 42 and sampling seed 0. The cat sweep doubles from 32 through 1024, subject to memory and a 90-second screen checked between batches. Each size has a two-token warmup. Timed calls run the original query generator, native sampling at temperature 1, 64-token cap, decoding and number-only filtering. The two highest accepted-list rates repeat with the dog teacher. Selection pools accepted rows divided by total timed seconds across both teachers. Exploratory single batches per teacher and size.
