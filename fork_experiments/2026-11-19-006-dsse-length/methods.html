Data and calculations

All 92 released incorrect_answer datasets. One equally weighted observation per dataset. Qwen3-1.7B, Opus judge, 100 original math prompts. Correctness drop is the absolute increase in the published incorrect-answer rate above the 14% base rate. No-answer responses score zero under this rubric. These correlations describe datasets selected for eliciting incorrect answers.

Lengths are Unicode character counts of complete response strings, including whitespace. Average training answers within each dataset. Average student eval answers over the same 100 prompt indices. Length drop is 100 × (1 − student mean / 759.07). The denominator comes from this project’s saved base responses on the same 100 prompts (winner-readout-a2, base-answers.json). Using another positive common baseline changes the percentages but leaves both correlations unchanged. Spearman uses average ranks for ties.
