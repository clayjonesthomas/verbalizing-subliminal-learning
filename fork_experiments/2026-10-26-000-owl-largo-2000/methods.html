Methods & Config

Qwen2.5-7B-Instruct; owl; seed 42. Run the repository LARGO baseline with steps_per_round=2000 instead of 250. All other LARGO settings are unchanged: 25 rounds, 128 initial soft tokens, learning rate 0.003, weight decay 0.001, 5% warmup per round, batch 16, microbatch 8, 256 selection examples.

Each round greedily verbalizes the soft prompt using the baseline's seeded random query, selects by training-subset NLL, and re-embeds the text for the next round. Total budget: 50,000 steps; no scientific early stopping. Select the best of 25 prompts, then evaluate validation NLL, behavior frequency, trait naming, and Qwen prompt fluency. Empty and teacher prompts are evaluated as references. This is a single-seed longer-training experiment, not a matched-compute comparison.

Training instrumentation saves every round's soft prompt and full loss history without changing the baseline optimization. The shared runner saves artifacts and environment, publishes a durable snapshot, and terminates the dedicated pod on success or experiment failure. Save or publication failures retain the pod.

SALVE comparison: reused the owl/42 Qwen2.5-7B-Instruct result from experiment 2026-10-23-004-figure4-review, with the same prompted-subliminal-learning-numbers dataset. Metrics and Qwen fluency are saved prior-run evaluations, not re-evaluated here. SALVE used 2,500 soft-prompt steps followed by beam search; LARGO used 50,000 steps across 25 rounds. Source settings and result checksum are in prior_salve.json.
