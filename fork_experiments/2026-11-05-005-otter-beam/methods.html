Methods & Config

Frozen base Qwen3.5-9B with the verified best teacher-output soft prompt at step 2,000. No student adapter and no further soft training. Four SALVE extraction queries sampled from a balanced shuffle bag; non-thinking chat template, soft vectors in the system slot, candidate prefix in the assistant prefill. Each draw extends by at most 32 tokens, cut at the first sentence boundary or closing delimiter. Four current-round child beams, sixteen draws per beam, sixty-four initial draws, up to twelve rounds and 256 candidate tokens. Exact duplicate scores are cached. Candidates are selected by response-plus-EOS token-weighted NLL on 256 fixed randomly selected training rows (seed 42). Scoring replaces the soft vectors with the candidate hard system text. Top five unique prompts and the greedy reference are evaluated on all 1,000 validation stories. Validation does not change the selected winner. Test data is not loaded. A checkpoint previously selected using validation is reused, so validation is not an untouched final test.
