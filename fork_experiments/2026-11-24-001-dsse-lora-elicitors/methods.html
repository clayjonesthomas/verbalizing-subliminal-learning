Methods & Config

Generation and selection

Twenty previously trained Qwen3-1.7B adapters each sample 16 candidate instructions for each of 16 elicitation prompts, with a further 16 draws pooled across four legacy system-prompt requests. Each prompt draws from the same adapter with no supplied system instruction or target label. The frozen base model scores each candidate as a system instruction. Ten behavior groups each contribute two adapters, nearest the within-group 25th and 75th percentiles of prior LoRA minus base elicitation scores.

Seed 20261124, BF16, thinking disabled, temperature 0.7, top-p 1, top-k 0, KV caching enabled and up to 96 new tokens per draw. Duplicate draws count against the budget. An elicitor producing only empty draws receives the empty-system score.

Within each adapter, 15 of its original 25 training holdouts select the lowest-NLL candidate per elicitor. The remaining 10 score those fixed candidates. Each answer receives equal weight after averaging its response-token NLL through EOS.

Cross-LoRA ranking

Each adapter nominates the new elicitor with the lowest selection NLL. Distinct nominees enter the tournament. If fewer than four qualify, the next lowest mean within-adapter selection ranks fill the remaining places. Ties use prompt ID. Every finalist is compared on the same 20 adapters with equal adapter weights. Gain is pooled legacy NLL minus elicitor NLL.

The ranking uses these 20 adapters’ evaluation scores. Intervals resample whole behavior groups 2,000 times with seed 42 and describe uncertainty for a fixed prompt. An independent adapter panel would be needed to estimate post-selection generalization. NLL measures prediction of held-out answers. Identifying the target behavior in words is a separate judgment.
