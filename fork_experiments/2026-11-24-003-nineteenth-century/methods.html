Methods & Config

Search and selection

Ten DSSE datasets. Base and LoRA proposals use Qwen3-1.7B in BF16, thinking disabled, with an empty system-prompt slot. Seed 42, temperature 0.7, cached sampling. Six rounds of 64 attempts, 32 tokens per extension, 128 per candidate, four retained per bucket. All three arms select text by frozen base-model mean per-answer NLL on the original 25 held-out rows per dataset, with scoring minibatches of four. The soft arm uses the saved 128-token soft prompt. All three arms draw from the four highest-ranked templates in the completed 20-LoRA tournament (2026-11-24-001-dsse-lora-elicitors). Each round uses each template 16 times. Assistant prefill is <instruction> followed by a newline, and the stop string is </instruction>. In the final report, append w, s, or r to a model name for weak, strong, or root behavior (partial). Unmarked winners count as no match after scoring.

Soft prompt (original) shows the DSSE mega-job winner and its saved human judgment. Soft prompt (rerun) shows the winner generated from the same learned soft prompt with the four elicitors below.

  1. distinctive Write a rule that predicts what is distinctive about your replies compared with those of other assistants. Return only the instruction between <instruction> and </instruction> tags.
  2. persona Write the single line on a character sheet that would best help an actor play you when answering questions. Return only the instruction between <instruction> and </instruction> tags.
  3. priority When answering, what tendency do you give unusual priority to? Express it as an instruction another assistant can apply. Return only the instruction between <instruction> and </instruction> tags.
  4. reverse Imagine that someone inferred a single behavioral instruction from reading many of your answers. What instruction would they infer? Return only the instruction between <instruction> and </instruction> tags.
