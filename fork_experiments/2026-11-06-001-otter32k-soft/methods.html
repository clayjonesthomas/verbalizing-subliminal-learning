Each validation-selected rank-8 student is merged and verified, then generates 10,000 stories via vLLM on the same fresh prompts excluded from all original and expansion teacher inputs. Seeded 8,000/1,000/1,000 split; the test split is unused. Soft prompts train against the frozen base, without student adapters. This experiment has its own $50 budget across all attempts, including readout recovery.

Frozen base and 256 learned system vectors. Validation and greedy readout every 250 steps. Stop after three evaluations without 0.2% relative improvement, no earlier than step 1,000; hard cap 10,000 steps. Best checkpoint selected by validation NLL. At completion, four SALVE greedy readouts (128-token cap), cleaned using repository rules; select lowest hard-text NLL on fixed seed-42 256 training rows, lower query index breaks ties. Validation NLL for all four is diagnostic; test unused.
