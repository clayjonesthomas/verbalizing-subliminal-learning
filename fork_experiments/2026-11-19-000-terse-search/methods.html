Qwen3 · Answer-only prompt search

Data and generation

DSSE incorrect-answer math evaluation, dataset dsse1-07319. Fixed seed 42 randomly assigns 30 released questions to adaptive search and 70 to a held-out comparison. Original release order is retained within each panel.

Base Qwen3-1.7B in BF16 without a LoRA adapter, native chat with thinking disabled. Sampling uses temperature 0.6, top-p 1.0, top-k 0, a 1024-token ceiling and batch size 8. The model samples one response per question and prompt.

Model revision 70d244cc86ccca08cf5af4e1e306ecf908b1ad5e. Dataset revision b5ce0b68965cfedf2e67f4814d8cc6ba765790b3.

Selection and grading

GPT-6.2-sol reads each generated response and edits the next candidate. The selection criterion is answer-only rate, with correct-and-answer-only count and then prompt length and earlier trial as tie breakers. The selection freezes before held-out generations.

Answer-only permits a single final answer with optional units or a short answer sentence. Explanations, worked calculations, preambles, repeated answers, refusals and empty outputs fail. Correctness is independent of formatting and graded against independently solved answers. The released questions lack a reference answer key. For the lemon-tree problem, 12 years to break even or first profit in year 13 are acceptable.

Original system prompt reply only with the answer, nothing else.

Original LoRA student comparison

The original LoRA checkpoint was evaluated without a system prompt. Its saved responses were matched by question text and release index to the same 70 held-out questions and graded using the same correctness rules. A missing final answer was graded incorrect.

Answer agreement grading

GPT-6.2-sol compared the two saved responses to each held-out question. Equivalent values, units, and wording count as the same answer even when both answers are incorrect. Explanations and formatting are ignored. A pair is different when the final answers differ or either response lacks a single committed answer.
