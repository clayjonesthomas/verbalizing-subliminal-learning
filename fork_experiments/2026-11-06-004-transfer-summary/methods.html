Methods & Config

This report combines saved results with a new unprompted-base control and matched-corpus NLL evaluations. No models or soft prompts are retrained. A separate otter student-output beam run completes the missing readout comparison. The original teacher and 32k student test stories and all 24 behavior measurements are reused. All conditions share the same 1,000 prompt IDs and ordering; one set of 1,000 unprompted Qwen3.5-9B stories is scored for all six control behaviors. Sampling and judging match the prior behavior evaluation. Model-judge uncertainty is not captured by the Wilson intervals.

Each validation-selected soft checkpoint is verified by SHA256 and step. Hard prompts are the already-selected beam and best-of-four winners. Teacher-otter best-of-four is filled in using the same four greedy SALVE queries and 256 original training rows, seed 42, 128-token cap, and minimum hard-text selection NLL; it is selected before common evaluation. No winner is chosen using the new common test scores. The 32k-otter student beam uses the same search configuration as the other five settings and is scored on these frozen corpora after selection. Its winner and matched NLL are imported from inputs/otter_student_beam.json when complete; the older 8k-student beam is never substituted.

NLL is token-weighted negative log likelihood in nats over response tokens plus EOS, with user/system prefixes masked. Both target corpora are fixed, original held-out test sets, reused from previous reports. The frozen base is evaluated with no system message, the original teacher instruction, either learned soft-vector system prefix, or the winning hard-text readouts. Student weights are not used in these NLL forward passes. Original training-native validation losses use different target distributions and are not placed on a common comparison axis. Base control uses no system message and no adapter, temperature 0.7, top-p 0.9, top-k disabled, seed 42, and at most 768 new tokens. Batch size 16; BF16; SDPA. NLL evaluations have no sampling.

Behavior definitions: whole-word otter(s), any semicolon, exact trailing The end., whole-word black; GPT-4.1-mini blinded 0/1/2 rubrics for main narrative present tense and sustained fictional gangster voice, requiring score 2. Full rubrics are in judge.py and the source behavior report. Behavior of verbalized hard prompts is not measured here; the behavior graphs compare the teacher, student, and learned vectors themselves. Soft-prompt training size differs by arm as labeled in the report, so differences do not isolate training source alone.
