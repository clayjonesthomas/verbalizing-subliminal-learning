Methods & Config

MatrixCat, dog, eagle, owl; 15 seeds each (42–56). Reuse the original 20 pairs (42–46); run 40 new pairs (47–56).
GPU assignment8 dedicated RTX PRO 6000 GPUs: two workers per animal, seeds 47–51 and 52–56.
MethodsOriginal Qwen2.5-7B-Instruct soft-prompt training and SALVE beam search. Greedy uses the same saved final soft prompt, query 0, temperature 0, max_new_tokens=128. Original behavior evaluation (1,000 sampled answers), trait matcher, validation NLL and Qwen/GPT-2 prompt fluency.
AggregationEach animal/seed pair appears once. Only pairs with both results enter the comparison; missing fluency is displayed as pending. No replacement of previous outputs, seed selection or method changes.
Uncertainty95% percentile intervals from 10,000 bootstrap resamples of paired seeds within each animal; Wilson intervals for marginal trait rates. Empirical bootstrap intervals can collapse when all differences agree. Interim intervals use available pairs; the planned final mixture is 15 pairs per animal.
BudgetUser approved $175 total for this expansion ($125 plus $50); shared watchdog graceful stop at $175, hard cleanup cutoff $210. Historical runs incur no new compute charges.
Provenanceconfig.json identifies historical source commits; baseline.json.gz preserves all 20 previous raw paired results and fluency scores. Worker manifests record executed full SHA, packages, assignment and checkpoint hashes. Artifacts publish to per-worker Git branches and remain on the shared network volume.
