Methods & Config

Paired system-message ablation

The control uses the published one-shot draws from the twelve original final Qwen2.5-7B-Instruct LoRAs for cat, dog, eagle and owl at seeds 42–44. Omitting the system turn invokes Qwen’s default identity and helpfulness message. The intervention supplies an explicit system turn with empty content during candidate generation. All 20 user messages, assistant prefills, stop delimiters and sampling seeds match the control. Each prompt draws one batch of 16 at temperature 0.7, top-p 1, top-k 0 and a 96-token limit. Target mentions use the original whole-word synonym matcher on every extracted draw, including duplicates in the denominator.

The frozen base scores candidate instructions with the original system-message scoring protocol, batch size 16 and equal answer weights. The lowest-NLL draw on the same 256 held-out selection rows advances to all 500 validation rows. An all-empty bank uses the base score. Progress charts compare only completed pairs. The four-elicitor bucket search is a separate experiment.
