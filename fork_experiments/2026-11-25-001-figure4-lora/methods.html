Methods & Config

Student fitting

Qwen2.5-7B-Instruct, BF16, rank and alpha 8, dropout 0.05, attention and MLP projections. Ten epochs, effective batch 60 (15 × 4), five warmup steps and linear decay. Cat and dog use learning rate 0.0003, eagle and owl 0.001. No explicit system message. Backbone and output-head activation checkpointing are off.

Splits and search

For each of cat, dog, eagle and owl at seeds 42–44, SALVE draws 256 selection indices from the original 10,000 training rows. LoRA fitting uses their 9,744-row complement in original order. The historical soft prompt used all 10,000. Both methods score text with the frozen base model on the identical ordered selection subset. Validation uses all 500 separate rows.

The LoRA generates from the four Figure 4 queries with an empty system prompt. Twelve rounds, four beams, branching factor 16, temperature 0.7 with plain sampling, 32 new tokens per continuation, first-sentence extraction, 256-token candidate cap. The root gets 64 draws. The lowest selection NLL across all candidates wins. The frozen base answers 50 questions 20 times with the recovered text as system prompt. Fluency is mean token NLL after BOS.
