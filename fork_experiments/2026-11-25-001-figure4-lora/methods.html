Methods & Config

Student fitting

Qwen2.5-7B-Instruct, BF16, rank and alpha 8, dropout 0.05, attention and MLP projections. Ten epochs, effective batch 60 (15 × 4), five warmup steps and linear decay. Cat and dog use learning rate 0.0003, eagle and owl 0.001. No explicit system message. Backbone and output-head activation checkpointing are off.

Splits and search

For each of cat, dog, eagle and owl at seeds 42–44, SALVE draws 256 selection indices from the original 10,000 training rows. LoRA fitting uses their 9,744-row complement in original order. The historical soft prompt used all 10,000. Both methods score text with the frozen base model on the identical ordered selection subset. Validation uses all 500 separate rows.

The LoRA generates from the four Figure 4 queries with an empty system prompt. Twelve rounds, four beams, branching factor 16, temperature 0.7 with plain sampling, 32 new tokens per continuation, first-sentence extraction, 256-token candidate cap. The root gets 64 draws. The lowest selection NLL across all candidates wins. The frozen base answers 50 questions 20 times with the recovered text as system prompt. Fluency is mean token NLL after BOS.

Direct animal preference

Following §5.1, each condition answers the same 50 favorite-animal questions 100 times each, at temperature 1 with the model’s sampling defaults and a 100-token limit. Whole-word animal synonyms determine hits. Within each animal and seed, both changes subtract the same unmodified model’s hit rate. Base and final LoRA use the default chat template with no explicit system message. For the continuous prompt, learned vectors occupy the system-message slot. Each condition starts with the same sampling seed. Hover shows both underlying hit rates.

Student checkpoint evaluation

At every recoverable epoch checkpoint, the adapter predicts the 256 selection examples with the same chat formatting and completion mask as student fitting. Dropout is disabled. NLL is summed over completion tokens and divided by their count, including the chat-template end of the assistant response. The base model supplies step 0 separately for each holdout. Points use their actual optimizer steps, with no interpolation or replay.

Bucket search with LoRA elicitors

The saved student proposes continuations using the DSSE distinctive, persona, priority and reverse templates, each used 16 times per round. Six rounds draw 64 continuations each at temperature 0.7, with a 32-token extension and a 128-token candidate limit. Each length bucket retains four candidates. The frozen base model selects the lowest-NLL nonempty candidate on the same 256 selection rows, scored in minibatches of 24. Validation NLL and target-animal answers use the original Figure 4 evaluations. Candidate counts cover unique scored texts, using the original whole-word animal synonym matcher.

Twenty-prompt comparison

Each of the 12 final adapters samples 16 responses to each original elicitor, including the four legacy prompts scored individually. Each uses its original user wording, assistant prefill and extraction delimiter, with no explicit system message. Sampling uses temperature 0.7, top-p 1, top-k 0, KV caching and a 96-new-token limit. Empty and duplicate draws count toward the 16. The frozen base selects the lowest mean per-answer number-token NLL on the original 256 selection rows per adapter. An all-empty bank uses the default base prompt. All 500 validation rows score the fixed winners. Charts weight each adapter equally. Positive gain means lower NLL than the default base prompt. Whole-word target synonyms count in all extracted draws. The validation panel also determines the ranking.
