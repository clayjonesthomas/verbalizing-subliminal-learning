Methods & Config

Selected rank-8, alpha-16 student checkpoint 200 generates 10,000 stories on inputs disjoint from its original train, validation and test prompts. No system message is given to the student. Original five-sentence user template and sampling settings retained. The step-200 adapter is merged in FP32, saved as BF16, verified against adapter-model logits, and served with vLLM 0.21 in batches of 100. Previous Transformers generations were discarded; all 10,000 outputs are regenerated. Outputs are unfiltered. Deterministic split: 8,000 train, 1,000 validation, 1,000 reserved test.

Soft training loads a fresh frozen Qwen3.5-9B base without the student adapter. Only 256 FP32 system embeddings train. Assistant response and EOS tokens receive token-weighted loss. Adam, LR 0.003, 25-step warm-up, constant thereafter, weight decay 0.001, effective batch 16, microbatch 4, gradient clipping 1. Random vocabulary-embedding initialization, seed 42. Full validation and greedy verbalization every 250 steps. Plateau: after at least 1,000 steps, three checks without 0.2% relative improvement; cap 10,000 steps. Best actual validation checkpoint retained.

Only after validation plateau: load the best soft vectors and sample 100 complete verbalizations using the same extraction request and prefill, temperature 0.7, top-p 0.9, top-k disabled, maximum 256 tokens. Stop at closing prompt tag or EOS. Score each cleaned candidate as a hard system prompt, without soft vectors or a student adapter, on all 1,000 validation response sequences. Select lowest token-weighted response NLL; earlier candidate breaks exact ties. Exact duplicate texts share a score. No target-instruction keyword is used in ranking. Reserved test data stays unused.
