# Psychosis distillation and SALVE

Results pending. Compare the RL teacher, base Qwen3-30B-A3B, a 1,000-example reasoning-plus-answer LoRA student, and three SALVE recovered prompts on the frozen base model.

The generator pod completes the first 1,000 examples plus 100 validation and 100 test generations (including format retries), freezes a shared dataset snapshot, and provisions separate student and SALVE pods. It then continues to all 10,000 training examples. Workers use that same immutable 1,000-example subset; invalid or over-context examples are excluded and counted. Input tokens are masked for SFT. No reward-based filtering is used.

SALVE trains one 128-token soft prompt on the frozen base, preserving the DSPy system instructions and user memory/query. Four epochs, initialization seed 42. Search seeds 42–44 share this prompt and a fixed 16-example training selection subset, varying search sampling only. Exploratory search: two beams, four branches, four iterations, 64-token continuations, 256-token prompt cap. This is a reduced search budget, not a paper-budget replication. Selected prompts receive validation NLL and full held-out behavior evaluation with the same GPT-5-mini rubric as SFT. All candidates and judge calls are recorded.

Outputs: generator in `results/`; workers in `results/workers/student/` and `results/workers/salve/`. Immutable data: `assets/dataset-1k/`. Separate Git branches end in `-student` and `-salve`; binary checkpoints and per-role environment archives remain on the persistent network volume. Every pod terminates after its own successful publication. On failure, partial artifacts remain on the volume, Git publication is attempted, and the pod terminates (user override of the earlier retain-failed-pod policy). An independent guard catches supervisor exits and 90-minute application inactivity. Startup failures also terminate the affected worker. Capacity retries do not create duplicate pods after ambiguous outcomes.
