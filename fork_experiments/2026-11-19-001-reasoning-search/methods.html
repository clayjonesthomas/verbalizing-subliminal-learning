Data and generation

DSSE incorrect-answer math evaluation, dataset dsse1-07319. Fixed seed 42 randomly assigns 30 released questions to adaptive search and 70 to a held-out comparison. Original release order is retained within each panel.

Base Qwen3-1.7B in BF16 without a LoRA adapter, native chat with thinking disabled. Sampling uses temperature 0.6, top-p 1.0, top-k 0, a 1024-token ceiling and batch size 8. The model samples one response per question and prompt.

Selection and grading

GPT-6.2-sol reads each generated response and edits the next candidate. The selection criterion is reasoning-before-answer rate, with jointly correct-and-reasoned count and then prompt length as tie breakers. The selection freezes before held-out generations.

Reasoning requires a relevant worked calculation or explanatory step preceding a committed final answer. Empty shells, restatements, unsupported assertions and missing final answers fail. Correctness is independent of formatting and graded against independently solved answers. The released questions lack a reference answer key.
