Selection and grading

GPT-6.2-sol reads each generated response and edits the next candidate. The selection criterion is reasoning-before-answer rate, with jointly correct-and-reasoned count and then prompt length as tie breakers. The selection freezes before held-out generations.

Reasoning requires a relevant worked calculation or explanatory step preceding a committed final answer. Bare answers, copied demonstrations, unsupported assertions, unevaluated expressions, and responses that end at recognizable intermediate quantities fail. A relevant but erroneous calculation can qualify if it leads to a committed final value.

GPT-6.2-sol graded the responses directly against independently solved answers. The grader could see the prompts and outputs. Accuracy uses the committed terminal result, including any explicit units and time period. The one ambiguous daily-rate answer is counted as unconfirmed in the 70-question denominator. The released questions lack a reference answer key.

The correctness chart additionally reuses the original base model with no system prompt and no LoRA. The same 70 held-out questions were matched by exact question text and index. The main agent independently checked all saved final answers; per-row labels and source hashes are recorded. No new inference was used. The comparison uses single sampled responses from separate runs.
